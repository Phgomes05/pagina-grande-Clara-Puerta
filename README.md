# Guia dos Estádios de São Paulo

Projeto acadêmico de um guia responsivo de estádios e eventos esportivos de São Paulo.

## Arquivos principais
- `index.html` — página inicial e cards dos estádios.
- `detalhe.html` — informações detalhadas dos locais.
- `estilo.css` — estilos, layout responsivo e acessibilidade.
- `.gitignore` — arquivos e pastas que não devem ser versionados.

## Tecnologias
HTML5 e CSS3.
